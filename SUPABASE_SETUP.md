# 🚀 Настройка Supabase для проекта

## Шаг 1: Создание аккаунта и проекта

1. **Зайдите на [Supabase](https://supabase.com)**
2. Нажмите **"Start your project"** или **"Sign in"**
3. Войдите через GitHub (рекомендуется)

4. **Создайте новый проект:**
   - Нажмите **"New Project"**
   - Выберите организацию (или создайте новую)
   - Заполните форму:
     - **Name**: `boost-platform` (или любое имя)
     - **Database Password**: Придумайте надежный пароль (сохраните его!)
     - **Region**: Выберите ближайший регион (например, `Europe (Frankfurt)`)
     - **Pricing Plan**: Выберите **Free** (бесплатно)
   - Нажмите **"Create new project"**

5. **Подождите 2-3 минуты** пока проект создается

---

## Шаг 2: Получение DATABASE_URL

1. После создания проекта перейдите в **Settings** (⚙️ в левом меню)
2. Выберите **Database** в боковом меню
3. Прокрутите вниз до раздела **"Connection string"**
4. Выберите вкладку **"URI"**
5. Скопируйте строку подключения, она выглядит так:
   ```
   postgresql://postgres.xxxxxxxxxxxxx:[YOUR-PASSWORD]@aws-0-eu-central-1.pooler.supabase.com:6543/postgres
   ```
6. **Замените `[YOUR-PASSWORD]`** на пароль, который вы создали в Шаге 1

---

## Шаг 3: Настройка проекта

1. **Откройте файл `.env`** в корне проекта
2. **Замените** строку `DATABASE_URL` на вашу:
   ```env
   DATABASE_URL=postgresql://postgres.xxxxxxxxxxxxx:ВАШ_ПАРОЛЬ@aws-0-eu-central-1.pooler.supabase.com:6543/postgres
   ```

---

## Шаг 4: Применение миграций

Откройте терминал и выполните:

```bash
# Перейдите в директорию БД
cd lib/db

# Установите зависимости (если еще не установлены)
pnpm install

# Примените миграции
pnpm run setup
```

Вы должны увидеть:
```
✅ Подключение успешно!
📦 Применение миграций...
✅ Миграции применены успешно!

📊 Созданные таблицы:
   ✓ users
   ✓ boosters
   ✓ orders
   ✓ reviews
   ✓ transactions

🎉 База данных готова к использованию!
```

## Шаг 5: Проверка в Supabase Dashboard

1. Вернитесь в Supabase Dashboard
2. Перейдите в **Table Editor** (📊 в левом меню)
3. Вы должны увидеть все созданные таблицы:
   - users
   - boosters
   - orders
   - reviews
   - transactions

## 📊 Структура базы данных

### Таблицы:

1. **users** - Пользователи (клиенты, бустеры, админы)
2. **boosters** - Профили бустеров с опытом и рейтингом
3. **orders** - Заказы на буст рангов
4. **reviews** - Отзывы о бустерах
5. **transactions** - Финансовые операции

### Связи:

- Один пользователь может быть бустером
- Один пользователь может создать много заказов
- Один бустер может выполнить много заказов
- Каждый заказ может иметь один отзыв

## ❓ Проблемы?

### Ошибка подключения:
- Проверьте правильность DATABASE_URL
- Убедитесь, что заменили `[YOUR-PASSWORD]` на реальный пароль
- Проверьте, что проект в Supabase активен

### Ошибка "already exists":
- Это нормально, если таблицы уже созданы
- Скрипт автоматически пропускает существующие таблицы
